해당 화면은 회사책무관리자·담당자 전용입니다.

1411 임원 및 겸직정보 등록 동영상 가이드


책무임원 인사정보 가져오기

  1. 상단의 인사정보 가져오기 버튼을 클릭합니다.
  2. 「인사정보 가져오기」 팝업이 열리면, 임원 정보를 확인한 후 적용 버튼을 클릭하여 가져옵니다.

    📌 책무임원은 [1029 사원정보관리] 화면에서 '책무임원'으로 지정된 사원 정보를 가져옵니다.

겸직정보 등록하기

※ 책무기술서에 표시할 겸직 정보를 등록합니다.

  1. 등록하고자 하는 임원의 (직무겸직) 버튼을 클릭합니다.

  2. 「직무겸직」 팝업이 열립니다.

  3. 사내 (직무)겸직 등록하기
    a. [사내 탭]을 선택한 후 등록 버튼을 클릭합니다.
    b. 신규 행이 추가되면 겸직명과 적용시작일을 입력합니다.
    c. 저장 버튼을 클릭하여 저장합니다.

  4. 사외 겸직 등록하기
    a. [사외 탭]을 선택한 후 등록 버튼을 클릭합니다.
    b. 신규 행이 추가되면 사외겸직 정보를 입력합니다.
    c. 저장 버튼을 클릭하여 저장합니다.
