====================================================================
AssetERP - A-Man (도움말/매뉴얼) 보안 연동 배포 및 검증 가이드 (관리자용)
====================================================================

본 가이드는 외부망 차단 상태에서 AssetERP 세션 기반으로 A-Man 도움말 시스템에
안전하게 단일 로그인(SSO) 방식으로 진입하기 위한 JSP 배포, GWT 소스 수정,
DB 설정 방법 및 테스트 검증 시나리오에 대해 설명합니다.

기존 레거시 도움말인 `user_manual.jsp`는 보존하며, 충돌 및 부작용을 예방하기 위해
신규 게이트웨이 파일인 `aman_opener.jsp`를 배포합니다.

--------------------------------------------------------------------
1. 파일 배포 방법 (JSP 파일 업로드)
--------------------------------------------------------------------
* 대상 파일: `aman_opener.jsp`
* 배포 경로: AssetERP WAS(Tomcat)의 webapps 루트 디렉토리
  - 예시 경로: `/home/kdy987/tomcat/apache-tomcat-8.5.100/webapps/ROOT/`
* 적용 시점: 복사 즉시 WAS에 의해 동적 컴파일되어 자동 적용됩니다. (WAS 재기동 불필요)

--------------------------------------------------------------------
2. GWT 소스코드 반영 방법 (MainFrame.java 수정)
--------------------------------------------------------------------
도움말 호출 시 사용자의 `personId`를 안전하게 쿼리 스트링에 결합하기 위해 GWT 소스코드를 다음과 같이 수정합니다.

* 대상 파일: `myApp/client/vi/MainFrame.java` (약 294 라인)
* 수정 전:
  ```java
  manualing.addMouseDownHandler(new MouseDownHandler() {
      @Override
      public void onMouseDown(MouseDownEvent event) {
          if(menualUrl != null) {
              String setting = "width=1200,height=800,menubars=0,toolbars=0,location=0,scrollbars=yes";
              Window.open(menualUrl, "help menual", setting);
          }
      }
  });
  ```
* 수정 후:
  ```java
  manualing.addMouseDownHandler(new MouseDownHandler() {
      @Override
      public void onMouseDown(MouseDownEvent event) {
          if(menualUrl != null) {
              String setting = "width=1200,height=800,menubars=0,toolbars=0,location=0,scrollbars=yes";
              
              String menualUrl2 = menualUrl;
              if (menualUrl2 != null) {
                  // 이미 URL 내에 ?가 있으면 &로 결합, 없으면 ?로 결합 (URL 오작동 방지)
                  String separator = menualUrl2.contains("?") ? "&" : "?";
                  menualUrl2 = menualUrl2 + separator + "personId=" + LoginUser.getUserId();
                  
                  Window.open(menualUrl2, "help menual", setting);
              }
          }
      }
  });
  ```
* 적용 시점: GWT 컴파일러를 통해 빌드를 재수행하고 빌드 결과물(js)을 운영 서버에 배포해야 적용됩니다.

--------------------------------------------------------------------
3. 데이터베이스 설정 방법 (URL 업데이트)
--------------------------------------------------------------------
* 대상 파일: `update_menu_url.sql`
* 처리 내용:
  - AssetERP의 각 화면 도움말 클릭 시 `aman_opener.jsp`를 호출하도록 sys06_menu 테이블을 수정합니다.
  - 예: `sys06_menual_url` 컬럼값을 `aman_opener.jsp?aka=화면식별코드`로 매핑.
* 실행 방법: SQL 스크립트 템플릿을 참고하여 개발/운영 DB 관리 도구에서 쿼리를 수행합니다.

--------------------------------------------------------------------
4. 외부망 및 사내망 테스트 검증 시나리오 (필수)
--------------------------------------------------------------------
배포를 마친 후, 외부망(AssetERP 회원사 대역) 및 사내망 PC 환경에서 아래 4가지 항목이 올바르게 차단 및 연동 작동하는지 검증을 완료해야 합니다.

### [테스트 1] A-Man 도움말 시스템 직접 진입 시 차단 여부
* **동작**: 브라우저 주소창에 `https://aview.k-fs.co.kr:7171/aman/docs`로 토큰 파라미터 없이 직접 접속합니다.
* **정상 결과**: 즉시 접속이 차단(403)되며, 만료 경고 전용 안내창(`/aman/expired`)으로 강제 이송되어야 합니다.

### [테스트 2] AssetERP를 경유한 SSO 정상 접속 여부
* **동작**: AssetERP에 로그인한 상태에서 각 화면의 [매뉴얼] 버튼을 클릭해 도움말을 호출합니다.
* **정상 결과**: `aman_opener.jsp`를 거쳐 일회성 토큰이 정상 검증되고, A-Man 페이지로 리다이렉트되어 도움말 트리가 정상적으로 표출되어야 합니다.

### [테스트 3] 15초 유효기간 만료 시 차단 여부
* **동작**: 도움말 버튼 클릭 시 생성된 URL 전체(토큰 포함)를 복사해둔 뒤, 15초가 경과한 후 해당 주소로 재접속을 시도합니다.
* **정상 결과**: 토큰 만료 판정을 받아 팝업창에서 "유효하지 않거나 만료된 보안 토큰입니다" 경고문이 노출되고 차단되어야 합니다.

### [테스트 4] 다른 PC에서의 불법 접속 차단 및 사내망 예외 사항
* **동작**: PC A에서 생성된 토큰 URL 주소를 복사하여 15초 이내에 다른 PC B의 웹 브라우저 주소창에 붙여넣고 접속을 시도합니다.
* **정상 결과**:
  - **서로 다른 네트워크(IP 대역이 다를 때)**: 15초 이내라 하더라도 다른 PC B에서는 접속이 차단됩니다. (토큰 내의 생성자 IP와 요청자 IP를 필터가 정밀 대조하기 때문)
  - **동일 사내망 내부(공인 IP 공유 시 - NAT 환경)**: 동일한 회사 내 공유기(공인 IP) 아래에 있는 PC B는 공인 IP가 동일하게 찍히므로 15초 이내라면 예외적으로 접속이 통과될 수 있습니다. (이는 NAT 환경의 공통 특성이나, 15초 제한 및 사내망 경계선 내로만 노출 범위가 통제되므로 보안 수준 상 정상 범위로 판단합니다.)
