====================================================================
AssetERP - A-Man (도움말/매뉴얼) 보안 연동 배포 가이드 (관리자용)
====================================================================

본 가이드는 외부망 차단 상태에서 AssetERP 세션 기반으로 A-Man 도움말 시스템에
안전하게 단일 로그인(SSO) 방식으로 진입하기 위한 JSP 배포 및 DB 설정 방법입니다.

기존 레거시 도움말인 `user_manual.jsp`는 보존하며, 충돌 및 부작용을 예방하기 위해
신규 게이트웨이 파일인 `aman_opener.jsp`를 배포합니다.

--------------------------------------------------------------------
1. 파일 배포 방법 (JSP 파일 업로드)
--------------------------------------------------------------------
* 대상 파일: `aman_opener.jsp`
* 배포 경로: AssetERP WAS(Tomcat)의 webapps 루트 디렉토리
  - 예시 경로: `/home/kdy987/tomcat/apache-tomcat-8.5.100/webapps/ROOT/`
* 적용 시점: 복사 즉시 WAS에 의해 동적 컴파일되어 자동 적용됩니다. (WAS 재기동 불필요)

--------------------------------------------------------------------
2. 데이터베이스 설정 방법 (URL 업데이트)
--------------------------------------------------------------------
* 대상 파일: `update_menu_url.sql`
* 처리 내용:
  - AssetERP의 각 화면 도움말 클릭 시 `user_manual.jsp`가 아닌 신규 게이트웨이인 `aman_opener.jsp`를 호출하도록 sys06_menu 테이블을 수정합니다.
  - 예: `sys06_menual_url` 컬럼값을 `aman_opener.jsp?aka=화면식별코드`로 매핑.
* 실행 방법: SQL 스크립트 템플릿을 참고하여 개발/운영 DB 관리 도구에서 쿼리를 수행합니다.

--------------------------------------------------------------------
3. 정상 연동 확인 방법
--------------------------------------------------------------------
1. AssetERP 로그인 후 화면 상단의 도움말 또는 개별 메뉴의 매뉴얼 버튼을 클릭합니다.
2. `aman_opener.jsp`를 통과하며 15초 유효의 일회용 토큰이 생성되고, 브라우저가 A-Man 서버로 자동 리다이렉트됩니다.
3. A-Man 도움말 화면이 정상적으로 표시되는지 확인합니다.
4. (보안 확인) AssetERP 로그아웃 상태에서 직접 `http://[ERP-도메인]/aman_opener.jsp`로 접속 시 "접근 권한이 없습니다" 경고 화면이 정상 표시되는지 검증합니다.
