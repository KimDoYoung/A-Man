# 이미지편집 형광펜 기능 설계 (이미지편집-형광펜기능-설계.md)

이미지 편집기에서 마우스로 쭉 그으면 **사람이 형광펜으로 칠한 것처럼** 강조되는 도구를 추가한다.

관련 코드: `frontend/src/components/imageditor/`

---

## 1. 결정 사항

| 항목 | 결정 |
|---|---|
| 색 | 노랑·분홍·연두·하늘·주황 5색 (실제 형광펜에 가까운 밝은 색) |
| 두께 | 가늘게 / 보통 / 굵게 3단계 |
| 진하기 | 연하게 / 보통 / 진하게 3단계 (투명도) |
| Shift + 드래그 | **수평 직선** (글자 한 줄을 반듯하게 칠하기) |
| 지우개 | 없음. 획 단위로 선택 후 Delete (기존 방식) |
| 크기 조절 손잡이 | 없음 (손으로 그은 선을 늘리면 어색함). 이동·색·두께·진하기만 변경 |
| 그리는 순서 | **항상 다른 도형 아래** (화살표·글자가 형광펜 색에 물들지 않도록) |
| 서버 | 변경 없음 (도형은 JSON으로 저장되므로) |

---

## 2. "사람이 칠한 것처럼" 보이게 하는 방법

1. **곱하기 합성** — `ctx.globalCompositeOperation = 'multiply'`
   - 흰 바탕만 형광색으로 물들고 **검은 글씨는 검게 그대로** 보인다 (실제 형광펜과 같은 원리).
   - 단순 반투명 덮기(`source-over`)는 글씨까지 흐려진다.
2. **굵고 끝이 둥근 선** — `lineCap = 'round'`, `lineJoin = 'round'`
3. **한 획은 한 번에 칠하기** — 점 전체를 하나의 path로 만들어 `stroke()` 1회
   - 한 획 안에서 선이 겹쳐도 그 부분만 진해지지 않는다.
   - 서로 다른 획이 겹치면 진짜 형광펜처럼 조금 더 진해진다 (곱하기 합성의 자연스러운 결과).
4. **손떨림 보정**
   - 점 줄이기: 직전 점과 2px 미만 떨어진 점은 버린다 (저장 데이터도 작아짐).
   - 부드럽게 잇기: 점 사이 중간점을 이용한 2차 곡선(`quadraticCurveTo`)으로 그린다.
5. **Shift + 드래그 = 수평 직선** — 시작점과 현재 x만 쓰고 y는 시작점에 고정 (점 2개)

## 3. 데이터 구조

`image_editor_types.ts`의 `CanvasItem`에 타입과 필드를 추가한다.

```ts
type: ... | 'highlighter'
points?: { x: number; y: number }[]   // 형광펜 획의 점들 (x, y 기준 상대좌표)

// 형광펜이 쓰는 기존 style 필드
style.borderColor   // 색
style.borderWidth   // 두께(px)
style.opacity       // 진하기(%)
```

### 3.1 좌표 저장 방식 (핵심)

- `x, y` = 획 전체를 감싸는 사각형의 왼쪽 위 (선 두께 포함)
- `width, height` = 그 사각형의 크기
- `points` = **x, y 기준 상대좌표**

→ 이동·자르기(crop)·위/아래 맞춤 등 **기존 함수가 `x, y`만 바꿔도 획 전체가 따라 움직인다.**
`itemGeometry.ts`의 `offsetItemForCrop`, `shiftItemX/Y`는 수정 없이 동작하고,
범위 계산(`getItemEdgeBounds`, `isItemWithinCropBounds`)은 box처럼 `x, y, width, height`를 쓰도록 형광펜 타입만 추가한다.

### 3.2 기존 작업과의 호환

- 새 타입·새 선택 필드만 추가하므로 **기존에 저장된 이미지 작업(`image_work.json_data`)은 그대로 열린다.**
- 형광펜이 들어간 작업을 이전 버전 화면에서 열면 형광펜만 보이지 않는다 (오류 없음).

## 4. 기본값과 색·두께

`image_items_defaults.ts`

```ts
// SYSTEM_ITEM_DEFAULTS 에 추가
highlighterColor: '#FFF200',   // 노랑
highlighterWidth: 20,          // 보통
highlighterOpacity: 45,        // 보통 (%)

export const HIGHLIGHTER_COLORS = ['#FFF200', '#FF7EC7', '#B2FF59', '#7FD4FF', '#FFB347'] // 노랑·분홍·연두·하늘·주황
export const HIGHLIGHTER_WIDTHS = [{ label: '가늘게', value: 12 }, { label: '보통', value: 20 }, { label: '굵게', value: 30 }]
export const HIGHLIGHTER_OPACITIES = [{ label: '연하게', value: 30 }, { label: '보통', value: 45 }, { label: '진하게', value: 60 }]
```

- 마지막으로 쓴 색·두께·진하기는 다른 도구처럼 사용자 설정(`StyleConfig`, `/admin/user-settings`)에 저장한다.

## 5. 화면·조작

### 5.1 도구 목록과 단축키

- 좌측 도구 목록에 `0:형광펜` 추가 (아이콘: lucide `Highlighter`). 위치는 텍스트(8)와 자르기(9) 다음
- 단축키 **`0`** (`NUMBER_KEY_TOOLS`에 추가. 1~9는 기존 도구가 사용 중)

### 5.2 마우스 동작

| 동작 | 결과 |
|---|---|
| 형광펜 도구에서 누르고 끌기 | 지나간 자리에 실시간으로 형광펜이 그려짐 |
| Shift 누른 채 끌기 | 시작 높이 그대로 수평 직선 |
| 떼기 | 획 1개가 도형으로 저장 (Undo 기록). 점이 1개뿐(클릭만)이면 저장 안 함 |
| 선택 도구로 획 근처 클릭 | 선택 (획과의 거리 ≤ 두께/2 + 4px) |
| 선택 후 끌기 | 이동 |
| 선택 후 Delete | 삭제 |
| 선택 후 Ctrl+D | 복제 (기존 기능) |

### 5.3 속성 패널 (`FloatingPropertyPanel.tsx`)

선택한 형광펜 또는 형광펜 도구 사용 중일 때:
- 색: 5색 팔레트
- 두께: 가늘게 / 보통 / 굵게
- 진하기: 연하게 / 보통 / 진하게

## 6. 구현 위치 (`ActionImageEditor.tsx`)

| 부분 | 내용 |
|---|---|
| 상태 | `activeTool` 타입에 `'highlighter'`, 그리는 중인 점 목록 상태 |
| 그리기 | 도형 그리기 루프(`items.forEach`) **직전에** 형광펜만 먼저 그림 → 항상 다른 도형 아래. 선택 시 감싸는 사각형 점선 표시 |
| 미리보기 | 드래그 중인 획을 같은 방식(곱하기 합성)으로 표시 |
| 선택 판정 | 기존 판정 루프에 형광펜 추가: 점 사이 선분과의 거리(`getDistanceToSegment`) |
| 이동 | 기존 이동 처리 재사용 (x, y만 변경) |
| 스타일 매핑 | `buildItemStyleFromConfig`, 기본값 적용 함수에 형광펜 추가 |
| 그리기 함수 | `canvasDrawHelpers.ts`에 `drawHighlighter(ctx, item)` 추가 (곱하기 합성, 둥근 끝, 2차 곡선) |

- 최종 PNG 내보내기(`toDataURL`)는 같은 캔버스를 쓰므로 추가 작업 없음.

## 7. 확인 항목

- [ ] 흰 바탕 위 검은 글씨: 글씨는 검게, 바탕만 형광색
- [ ] 한 획 안에서 겹쳐 그어도 겹친 부분이 진해지지 않음
- [ ] Shift 수평 직선
- [ ] 형광펜 위에 그린 화살표·글자가 형광색에 물들지 않음 (형광펜이 항상 아래)
- [ ] 선택·이동·삭제·복제, 색·두께·진하기 변경
- [ ] Undo / Redo
- [ ] 자르기 후 위치 유지, 저장 후 다시 열기, PNG 내보내기
- [ ] 기존에 저장된 이미지 작업이 그대로 열림
- [ ] 기존 도구(1~9) 동작 변화 없음

## 8. 진행 현황

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 설계 문서 | 완료 |
| 2 | 타입·기본값·그리기 함수 | 완료 |
| 3 | 편집기: 도구·그리기·선택·이동·Undo | 완료 |
| 4 | 속성 패널 | 완료 |
| 5 | lint·빌드 | 완료 / 화면 확인(사용자) 대기 |

### 구현 메모

- 새 파일 `highlighter.ts`: 점 추가(손떨림 보정·Shift 수평선), 도형 생성(감싸는 사각형 + 상대좌표), 그리기(곱하기 합성), 선택 판정
- `ActionImageEditor.tsx`: 도구 `0:형광펜`, 그리기 전용 1차 패스(다른 도형보다 먼저 = 아래), 드래그 미리보기,
  선택 판정은 **다른 도형이 잡히지 않을 때만** 형광펜 검사, 이미지 크기 조정 시 점 좌표도 비율 변경,
  기본값 저장·복원·변경 감지에 3개 설정(`highlighterColor/Width/Opacity`) 연결
- 그은 뒤에도 도구를 유지하고 새 획은 선택하지 않음 → 여러 줄을 연달아 칠하기 편하도록
- 선택한 획의 두께를 바꾸면 감싸는 사각형과 점 좌표를 두께 차이만큼 다시 맞춤
- 이동·복제(Ctrl+D)·방향키 이동·바탕 확장·자르기는 기존 처리(x, y 변경) 그대로 동작
- 검증: lint 통과, 타입 오류 수 변화 없음(기존 42건), 빌드 성공,
  `highlighter.ts` 함수 실행 검사(점 줄이기, 수평선, 짧은 획 무시, 상대좌표 복원, 이동 후 판정, multiply·stroke 1회·곡선)
