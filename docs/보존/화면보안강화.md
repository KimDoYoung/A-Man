# A-Man - 화면 보안 및 콘텐츠 유출 방지 강화 방안 (화면보안강화.md)

이 문서는 A-Man 매뉴얼 시스템 내의 노하우 및 업무 흐름 정보가 경쟁사 등으로 유출되는 것을 차단하기 위해, **브라우저 단(Frontend)과 API 통신 단에서 적용할 수 있는 강력한 유출 방지 기법**을 정리한 가이드라인 및 소스코드 수정 계획입니다.

웹 브라우저 환경 특성상 100% 완벽한 유출 차단은 불가능하지만, **"유출에 드는 기술적 비용과 귀찮음을 극대화"**하여 일반 사용자 수준은 물론, IT 기술을 가진 인력의 유출 시도까지 효과적으로 저지하는 것을 목적으로 합니다.

A-Man의 두 가지 진입 경로인 **React 뷰어(/docs)**와 **Java 뷰어(/manual)** 모두에 아래 소스 수정을 적용합니다.

### 3.1 React 프론트엔드 영역 수정 (/docs)

React는 `/docs/page/:page_id` 진입 시 `MarkdownViewer.tsx` 컴포넌트가 활성화되므로, 관련 파일 3곳을 수정합니다.

#### 1) [NEW] `frontend/src/utils/useSecurity.ts`
컴포넌트 단위에서 우클릭 방지, 복사 방지, 단축키 차단, 무한 디버거 기동, F12 창 실시간 오픈 감시를 수행하는 React 커스텀 훅을 생성합니다. (단, 고의적인 디버거 구문 및 빈 예외 처리 블록의 빌드 시 ESLint 스타일 경고 방지를 위해 최상단에 예외 주석을 선언합니다.)

```typescript
/* eslint-disable no-debugger, no-extra-semi, no-empty */
import { useEffect } from 'react'

export function useSecurity(enabled: boolean = true) {
  useEffect(() => {
    if (!enabled) return

    // 1. 우클릭 및 텍스트 드래그/선택 시작 방지
    const handleContextMenu = (e: MouseEvent) => e.preventDefault()
    const handleSelectStart = (e: Event) => e.preventDefault()
    const handleCopy = (e: ClipboardEvent) => {
      e.preventDefault()
      alert('보안 정책상 매뉴얼 텍스트를 복사할 수 없습니다.')
    }

    // 2. 단축키 제한 (F12, Ctrl+Shift+I/C/J, Ctrl+S/P/U)
    const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key === 'F12' || e.keyCode === 123) {
        e.preventDefault()
        return
      }
      if (
        e.ctrlKey &&
        e.shiftKey &&
        (e.key === 'I' || e.key === 'C' || e.key === 'J' || e.keyCode === 73 || e.keyCode === 67 || e.keyCode === 74)
      ) {
        e.preventDefault()
        return
      }
      if (
        e.ctrlKey &&
        (e.key === 's' || e.key === 'p' || e.key === 'u' || e.key === 'S' || e.key === 'P' || e.key === 'U' || e.keyCode === 83 || e.keyCode === 80 || e.keyCode === 85)
      ) {
        e.preventDefault()
        return
      }
    }

    // 3. F12 개발자 도구 강제 활성화 감시 (도킹창 크기 비교 감지)
    const threshold = 160
    const checkDevTools = () => {
      const widthDev = window.outerWidth - window.innerWidth > threshold
      const heightDev = window.outerHeight - window.innerHeight > threshold
      if (widthDev || heightDev) {
        document.body.innerHTML = `
          <div style="display:flex;flex-direction:column;align-items:center;justify-content:center;height:100vh;font-family:sans-serif;color:#ef4444;background:#fafafa;padding:20px;text-align:center;">
            <h2>⚠️ 보안 경고</h2>
            <p>개발자 도구(F12)가 활성화되어 있어 시스템 접근이 제한됩니다.</p>
            <p>개발자 도구를 완전히 종료하신 후 페이지를 새로고침해 주십시오.</p>
          </div>
        `
        throw new Error("DevTools detected.")
      }
    }

    // 4. 무한 디버거(Anti-Debugging) 기동
    let debuggerTimeoutId: any
    const startAntiDebug = () => {
      const debuggerTimer = () => {
        try {
          ;(function a(i: number) {
            if (("" + i / i).length !== 1 || i % 20 === 0) {
              ;(function() {}).constructor("debugger")()
            } else {
              debugger
            }
            a(++i)
          })(0)
        } catch (e) {}
        debuggerTimeoutId = setTimeout(debuggerTimer, 200)
      }
      debuggerTimer()
    }

    document.addEventListener('contextmenu', handleContextMenu)
    document.addEventListener('selectstart', handleSelectStart)
    document.addEventListener('copy', handleCopy)
    document.addEventListener('keydown', handleKeyDown)
    window.addEventListener('resize', checkDevTools)

    // 즉시 감시 및 디버거 기동
    checkDevTools()
    startAntiDebug()
    const devToolsIntervalId = setInterval(checkDevTools, 500)

    return () => {
      document.removeEventListener('contextmenu', handleContextMenu)
      document.removeEventListener('selectstart', handleSelectStart)
      document.removeEventListener('copy', handleCopy)
      document.removeEventListener('keydown', handleKeyDown)
      window.removeEventListener('resize', checkDevTools)
      clearInterval(devToolsIntervalId)
      clearTimeout(debuggerTimeoutId)
    }
  }, [enabled])
}
```
