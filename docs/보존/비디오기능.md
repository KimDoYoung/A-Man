# 비디오기능

## 개요

1. 비디오기능을 마크다운 에디터에 넣어야 함.
2. 한국펀드서비스에서 자체 제작한 동영상을 서버에 업로드하고 삭제가능해야함.
3. 마크다운에디터에 비디오를 태그(?)를 삽입할 수 있어야함.
4. 일반사용자는 비디오를 웹브라우저 안에서 play할 수 있어야 함.


## 구현 전 고려 사항

1. 관리자 권한에서 '비디오 관리' 메뉴를 만들 것인가? 아니면 기존 '자산관리'에서 처리할 것인가?
2. 비디오가 현재는 3개라고 하는데 이것이 나중에 늘어날 가능성은 있음.
3. 비디오 관리를 새로 만든다면 테이블도 만들어야할까?
4. 백업에 비디오까지 고려해야할까? 아니면 그냥 비디오는 제외할까?

## 설계

1. 비디오를 관리하기 위한 테이블은 일단 보류, 파일시스템을 사용하자.
2. 태그는 image 태그를 사용하고 확장자를 판단하여 video html태그를 사용하는 것으로 하자
3. 관리자 메뉴에 '비디오 관리' 를 만들자.
4. 마크다운 에디터의 toolbar(topbar)의 이미지 옆에 비디오 버튼을 만들자.
5. 비디오 버튼 클릭시 추가할 수 있는 비디오 리스트가 나오는 팝업(최신이 먼저보이게끔)을 보여주고 선택하게 하자. 
   - ctrl+shift+v 와 엮는 것이 가능하면 좋겠음
6. '비디오 관리' 관리자 메뉴 클릭시, 비디오 리스트와 업로드 기능이 가능, 삭제 가능, 필터링 가능(Aggrid사용)
7. /docs, /manual(서버 랜더링) 모두 video 태그를 동일하게 넣어야함.
8. 비디오 부분이 브라우저의 넓은 영역을 차지하니 버튼으로 그 부분을 줄이는 것도 가능한가?
9. docs/video1.html에서와 같이 표현해 주면 좋을 듯.

## 개발 전 고려한 사항들

A-Man 시스템의 도움말 에디터 및 뷰어에서 마크다운 문장을 파싱할 때 동영상 재생이 가능하도록 처리하는 방안입니다.

DB에 저장된 마크다운 텍스트 원본을 읽어 클라이언트단(React 등)에서 HTML로 변환할 때, 아래의 2가지 접근 방식 중 선택하여 구현할 수 있습니다.
---

## 1. 표준 마크다운 문법 확장 방식 (자동 치환)

작성자가 마크다운의 기본 이미지 문법(`![대체텍스트](URL)`)으로 동영상 파일 경로를 입력하면, React 마크다운 렌더러가 URL 확장자(`.mp4`, `.webm`, `.ogv` 등)를 감지하여 자동으로 HTML5 `<video>` 태그로 변환하도록 구현하는 방식입니다.

### 작성 예시 (마크다운 원본)

```markdown
![AssetERP 전표 등록 가이드](http://jskn.iptime.org/aman/uploads/videos/guide.mp4)

```

### React / JS 변환 렌더링 로직 예시

`react-markdown` 컴포넌트를 사용 중인 경우 `img` 태그를 만났을 때 아래와 같이 확장자를 판별하여 `<video>` 태그를 반환하도록 처리합니다.

```jsx
import React from 'react';
import ReactMarkdown from 'react-markdown';

const MarkdownViewer = ({ content }) => {
  return (
    <ReactMarkdown
      components={{
        img: ({ node, src, alt, ...props }) => {
          // 동영상 확장자 체크 (.mp4, .webm, .ogg 등)
          const isVideo = src && src.match(/\.(mp4|webm|ogg)$/i);

          if (isVideo) {
            return (
              <video
                src={src}
                controls
                width="100%"
                style={{ borderRadius: '8px', margin: '10px 0' }}
              >
                {alt || '브라우저가 동영상을 지원하지 않습니다.'}
              </video>
            );
          }

          // 일반 이미지인 경우 기존 <img> 태그 반환
          return <img src={src} alt={alt} style={{ maxWidth: '100%' }} {...props} />;
        },
      }}
    >
      {content}
    </ReactMarkdown>
  );
};

export default MarkdownViewer;

```

## 2. 직접 HTML `<video>` 태그 사용 방식

마크다운 파서가 인라인 HTML 태그 사용을 허용하도록 설정되어 있다면, 본문에 HTML `<video>` 태그를 직접 작성하여 렌더링하는 것도 가능합니다.

### 작성 예시 (마크다운 원본)

```html
<video src="http://jskn.iptime.org/aman/uploads/videos/guide.mp4" controls width="100%" poster="http://jskn.iptime.org/aman/uploads/images/thumbnail.jpg">
  동영상을 지원하지 않는 브라우저입니다.
</video>

```

> 
> **설정 주의사항**: `react-markdown` 사용 시 HTML 태그를 인식하려면 `rehype-raw` 플러그인을 컴포넌트에 적용해두어야 태그가 이스케이프 처리되지 않고 HTML로 렌더링됩니다.

## 3. 동영상 스트리밍 서버 설정 체크 포인트

서버에 올린 동영상 파일의 특정 재생 구간으로 이동(Seek)하거나 원활하게 스트리밍되도록 하기 위해서, 백엔드(Spring Boot) 및 Nginx 환경에서 **`HTTP Range Requests (206 Partial Content)`** 응답이 지원되어야 합니다.

* 
**Spring Boot**: 정적 자원 핸들러(`ResourceHandlerRegistry`)를 통해 동영상 폴더를 매핑하면 표준 Range 요청을 자동으로 지원합니다.


* 
**업로드 용량 제한**: 동영상 업로드 API의 최대 용량 제한(`spring.servlet.multipart.max-file-size`)을 100MB 이상으로 충분히 설정합니다.
