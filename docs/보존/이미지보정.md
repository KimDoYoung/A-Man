# 포커스 해제 및 선택/이동 모드 전환 기능 구현 계획

## 목표
- 이미지 에디터 내에서 속성 값 조절 컨트롤(`RangeSlider`의 슬라이더/인풋창, 다음번호 입력창 등)에 포커스가 잡힌 채로 **Escape(ESC)** 키를 입력하면, 포커스가 그곳에 계속 남아 단축키 등이 동작하지 않는 문제를 해결합니다.
- 조작 흐름 개선안:
  - 포커스가 활성화된 인풋 필드나 슬라이더에서 **Escape**를 누르면 포커스가 정상 해제(blur)되도록 처리합니다.
  - 동시에 에디터를 **'선택/이동'(pointer)** 모드로 즉시 전환하여 연속적인 키보드 편집이 가능하도록 사용성을 제고합니다.
- Props 구조를 해치지 않으면서 효율적인 메시지 전송을 위해 window 커스텀 이벤트(`editor-escape`) 방식을 적용합니다.

## User Review Required
> [!NOTE]
> - `RangeSlider.tsx`의 수동 입력 폼 및 기본 범위(range) 슬라이더, 그리고 `FloatingPropertyPanel.tsx`에 표시되는 원숫자의 '다음번호' 입력창에서 ESC 키가 정상 작동하도록 수정합니다.
> - 이로 인해 마우스를 쓸 필요 없이 키보드 ESC로 포커스를 풀고 즉시 pointer 모드로 돌아갈 수 있게 됩니다.

5. 에디터에서 원숫자를 하나 드로잉하여 생성하고 선택 상태로 만듭니다.
6. 우측 인스펙터 패널에 나타난 '다음번호' 인풋 필드나 '글자 크기' 슬라이더를 조절하여 값을 바꾼 뒤 **ESC** 키를 입력합니다.
7. 포커스가 즉시 풀리고 '선택/이동' 모드로 원활하게 변경되는지 검증합니다.
