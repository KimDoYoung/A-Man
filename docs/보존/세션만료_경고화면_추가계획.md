# 세션 만료 및 권한 오류 전용 경고 페이지 추가 계획서 (세션만료_경고화면_추가계획.md)

이 계획서는 일반 사용자가 A-Man 도움말에 직접 접속을 시도했거나 보안 토큰이 만료되었을 때, 관리자 로그인 화면(`/aman/login`)으로 튕기는 대신 친절한 안내 메시지를 제공하는 전용 경고 컴포넌트(`SessionExpireWarning.tsx`) 및 라우팅 추가 방안을 명시합니다.

---

## 1. 개요 및 필요성

* **현재 상황**: 일반 사용자(ERP 직원 등)가 도움말 접속 도중 세션이 끊기거나 직접 접속 시 403 API 오류가 나면, 프론트엔드가 일괄적으로 어드민 전용 로그인 페이지(`/aman/login`)로 강제 리다이렉트합니다.
* **문제점**: 일반 사용자는 A-Man 관리자 계정이 없으므로 로그인 화면을 보더라도 아무런 조치도 취할 수 없으며 혼란만 초래됩니다.
* **개선안**: 일반 매뉴얼 영역(비 `/admin` 경로)에서 인증 실패(403) 시에는 로그인 화면 대신 **"세션 만료 및 재접속 안내 페이지"**(`/aman/expired`)로 리다이렉트하고, 명확한 가이드를 제공합니다.
