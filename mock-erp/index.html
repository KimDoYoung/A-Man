🖥️ AssetERP 연동 테스트 대시보드 (Light Mode)

AssetERP 도움말 시스템(A-Man)의 보안 토큰 연동 및 IP 우회 설정을 검증하기 위한 가상 ERP 콘솔입니다.

Tomcat 가상 ERP 도메인 http://localhost:8080/aman-mock/
A-Man 백엔드가 감지한 내 IP (Remote IP) 불러오는 중...

💡 상세 보안 검증 시나리오 가이드

  • 시나리오 1. 토큰 없는 다이렉트 접근 차단 검증
    aman.security.internal-ip.enabled=false 로컬 설정을 끈 상태에서 크롬 시크릿 창을 열고 http://localhost:5173/aman/docs 또는 /manual/1318 주소로 직접 진입을 시도합니다.
    → 비인가 사용자로 판단하여 로그인 화면(`/aman/login`)으로 즉시 강제 리다이렉트 혹은 403 차단되는지 검증합니다.
  • 시나리오 2. 토큰 시간 초과(15초 만료) 검증
    우측의 [🔑 토큰 URL 생성하기] 버튼을 클릭해 토큰 주소를 생성 및 복사한 뒤 **15초를 대기**한 후 시크릿 창에 붙여넣어 봅니다.
    → "유효하지 않거나 만료된 보안 토큰입니다."라는 403 Forbidden 차단 페이지가 노출되는지 확인합니다.
  • 시나리오 3. 다른 기기(IP 불일치) 차단 검증
    [🔑 토큰 URL 생성하기]로 생성된 URL을 복사하여 15초 이내에 같은 네트워크의 **스마트폰 브라우저**에 입력하여 접속을 시도합니다.
    → 스마트폰 IP와 토큰 내 등록된 IP가 매칭되지 않으므로 접근 권한 없음(403)으로 자동 격리되는지 검증합니다.
